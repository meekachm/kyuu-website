# Kyuu — Filmmaker Portfolio

A static portfolio website for filmmaker Yutaro “Kyuu” Kudo, built with HTML, CSS, and JavaScript.

**Status:** Ongoing refinement. The site includes a work section, biography, contact links, and English/Japanese language switching. The featured music video is currently marked “Coming soon.”

## Features

- Work, About, and Contact sections.
- English/Japanese copy switched with JavaScript.
- A layout styled with CSS.
- Email and social links.
- A `CNAME` file for custom-domain hosting.

## Explore the code

| File | Purpose |

## Preview locally

Clone the repository and open `index.html` in a browser. No package installation or build step is required for this static site.

Alternatively, run a local server from the repository root:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Scope

This repository contains a filmmaker's portfolio website. The films, directing credits, and biography belong to the featured filmmaker; they are not software-development credits.
